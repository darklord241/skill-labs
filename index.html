Top 3 · Browser extension

O-note

A Chromium extension that adds a floating notes panel to LeetCode and Codeforces question pages, so notes live next to the problem they belong to.

  • Markdown editor with live preview and debounced autosave
  • Labels, plus a View page to search, filter by site or label and sort by last update
  • Alt+L toggles the panel, Alt+K switches between edit and preview
  • Notes stay local in IndexedDB, with Markdown export and JSON backup and import

Top 3 · Backend service

url-shortener

A URL shortening service built as a Spring Boot API on top of PostgreSQL. Short links save characters and are easier to copy, type and remember.

  • Java, Spring Boot and Maven, with a PostgreSQL database
  • Set up with an application.properties file and tested with curl or Postman
  • Roadmap: link expiry, click counts, custom short codes, a frontend and rate limiting

Top 3 · Geospatial analysis

heat-index

An analysis of the urban heat island effect over Bengaluru, built from Landsat 8 and 9 satellite imagery.

  • Python scripts convert raw digital numbers to surface reflectance, then compute NDVI from bands 4 and 5
  • Calibrated with Landsat Collection 2 coefficients and projected to UTM zone 43N
  • rasterio and numpy for the processing, QGIS project files for every output
  • Linear and random-forest model experiments are underway
